Credit Risk Prediction System with Explainable AI (SHAP) & Gradio UI

A complete machine learning system built to predict whether a loan applicant presents good or bad credit risk. Beyond just generating a risk label, it integrates SHAP values so that credit officers can understand the exact financial and demographic factors influencing each decision, presented in an interactive Gradio web interface.

Credit Risk Evaluation Interface — Live Output
Click to Inspect UI

HOW IT WAS BUILT

  • Preprocessing Pipeline: Cleaned and prepared tabular demographic and financial records using Pandas and Scikit-learn, handling categorical encoding and normalization.
  • Random Forest Model: Trained a balanced Random Forest Classifier to evaluate risk patterns while preventing overfitting on non-linear applicant attributes.
  • SHAP Explainability: Implemented SHapley Additive exPlanations to extract feature importances, breaking down individual applicant variables into understandable positive or negative contributions.
  • Joblib Model Serialization: Serialized the trained model and preprocessing transformers so inference can run instantly without retraining.
  • Interactive Gradio Interface: Created a clean browser frontend where users input applicant profiles and immediately receive prediction labels, confidence percentages (e.g., 68% Good / 32% Bad), and progress bar distributions.

PixelBridge — Zero-Buffer USB Media Synchronization Desktop App via ADB

A desktop application I built to automatically sync photos and videos between two Android devices connected via USB. Specifically designed to take advantage of unlimited Google Photos cloud backup on Google Pixel phones, transferring media without hogging laptop disk storage and preserving all original capture timestamps and EXIF data.

PixelBridge Desktop Application — Live Transfer Console
Click to Inspect UI

HOW IT WAS BUILT & SOLVED

  • Safe Single-File Buffer: Transferring 50GB+ of phone media usually fills up a laptop's drive. I engineered a single-file buffer: one photo/video is pulled from the sender device via ADB, immediately pushed to the target Pixel phone, verified, and deleted from the laptop buffer—consuming zero permanent laptop disk space.
  • Deadlock-Free Batching: Configured a structured batch process with state recovery so transfers don't crash or lock up midway through heavy 4K video files.
  • EXIF & Timestamp Preservation: Carefully maintained creation dates, camera metadata, and folder structures so Google Photos on the Pixel sorts every photo in chronological order.
  • Desktop UI: Created a clean desktop interface with device detection (Sender vs. Receiver), transfer progress bars, batch status controls, and a live protocol terminal feed.
